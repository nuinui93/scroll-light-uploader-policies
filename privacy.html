Scroll and Light Uploader is a private desktop utility operated by 김호균 for the operator’s own YouTube channels. It uses YouTube API Services. Google’s handling of data is described in the Google Privacy Policy. Use of the client is also subject to the YouTube Terms of Service.

Data accessed and why

The client reads the authorized YouTube channel’s ID and name to verify the destination. It reads playlist IDs and titles when the owner chooses a destination playlist. It submits the owner-selected local video, thumbnail, captions, title, description, tags, language, audience and visibility settings, and synthetic-media disclosure to YouTube. Upload responses provide the new video ID and returned status for checking the result.

The requested OAuth permissions are youtube.upload and youtube.force-ssl. These support video upload, upload-status updates, custom thumbnails, captions and playlist placement. Google handles account sign-in directly. The client does not collect a Google password.

Storage and sharing

OAuth tokens and desktop-client configuration are stored on the owner’s Mac with owner-only file permissions. Tokens are used only to communicate with Google’s authorization service and the YouTube API over HTTPS. This version displays API response data in memory and the local terminal; it does not create a persistent API response database or upload-result file. Original media and owner-written upload settings remain in their original local locations.

Data is sent to Google/YouTube to carry out the owner’s selected operation. The uploader does not sell data, send it to advertising services, or use it to train AI models. This desktop client contains no advertising, tracking cookies, embedded video player, or analytics SDK. The documentation host, GitHub Pages, logs visitors’ IP addresses for security. See the GitHub Privacy Statement.

Disconnect and delete

Run python3 youtube_api.py disconnect and confirm DISCONNECT. The client immediately asks Google to revoke the authorization, and removes its local token after Google confirms success. It stores no API response cache. Revocation can affect other channel tokens belonging to the same Google application grant.

You can also revoke access directly on the Google account permissions page.

To request deletion of any manually exported API information or legacy upload-result records held by the operator, email cutehokyun@gmail.com. The operator will delete that information as soon as possible and within seven calendar days of a deletion request or in-client revocation. The operator must refresh or delete any retained API data within 30 days and check for revoked Google permissions at least every 30 days. These legacy-record steps are manual; no unattended cleanup service is installed.

The client checks token validity when it is used and refreshes expired access tokens. If Google reports that authorization is no longer valid, this version removes the invalid local token. Original owner-created media are not API-fetched data and are not removed by disconnecting. Deleting local information does not delete content stored by YouTube; use YouTube Studio to manage that content.
